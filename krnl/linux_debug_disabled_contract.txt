Restricted disabled-breakpoint guest DR initialization, not complete debug virtualization
Static evidence fixed ELF 8101b146 xor eax,eax / 8101b148 MOV RAX,DR0 and following DR1/2/3/6/7 clears. Runtime operand always read from actual GPR/RSP, no RIP whitelist/assumption.
MOV DR reason29 and qualification maskf17 only, DR4/5 rejected (not architectural #UD emulation), CPL0 long mode and existing CR0/CR4 profile; actual primary MOVDR-exiting set. Guest VMCS DR7 must400, DEBUGCTL0, no TF/VM flag. Invalid/unsupported state fail-stop.
Per-CREATE software DR0..3 canonical48 addresses read/write while breakpoints remain disabled. DR6 accepts0 orffff0ff0 only, reads normalized no-eventffff0ff0. DR7 accepts0/400 only, retains VMCS400, reads400. Any enable/GD/status/other debug behavior rejected, never silently swallowed as working breakpoint. No new CPUID feature. #DB generation/delivery and active breakpoints NOT implemented.
All16 encoded register mappings including VMCS RSP supported. Read-toRSP writesRSP thenRIP; read-toGPR and addressbank only commit after RIP success. Failed uncertain write retains failed latch/noresume. No native MOVDR/host address write. Caller session already binds domain; reset only after guest resources released clears private addresses.
Native existing host DR7=400 DEBUGCTL=0 gates and DR6 restore remain unchanged; no DR0..3 guest hardware installation. Host isolation claim here is static path and mocked software tests, not new VM validation.
Full active debug requires separate reviewed native ownership/save/load/restore for DR0..3/6 on all entry/exit/fault paths, VMCS DR7/DEBUGCTL control, DR6 status semantics, GD/#DB/DR4/5 aliases and event arbitration. This patch intentionally does not expand native.
Reason29 added only as actual guest-instruction receipt for PF/IRQ; timer/vectoring/entryfail remain restricted. Clock/budget unchanged. Build MG_MODS += linux_debug_disabled; full recompile consumers of changed lgd_context layout.
Host sanitizer/freestanding tests: linux_debug_disabled_dispatch, linux_sysenter_dispatch, linux_invlpg_dispatch, linux_clock_dispatch. No VM runs by author.
