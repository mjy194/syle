Host-only correction after v12: no new Linux/VM execution authorized.
Observed v12 counter_pair=0, physical_base=0, pmd_flags=80000000000000e3, guest EFER=d01. The NX bit is legitimate: EFER.NXE is set and the early 2MiB mapping is for the boot-parameters REP MOVSL source data read, not instruction fetch. Current handler code runs in separately checked executable high-kernel mappings. Clearing NX would incorrectly broaden the guest data mapping permissions.
The new independent linux-high-pf-nx target preserves v12. Its production lhpd_metadata check requires the exact observed NX flags, exact EFER d01/base0, recursion low32 counter0 and allocator high32 <=62 (two slots remain). The recursion-zero requirement is stricter than old v12, matching measured state and fixed nonrecursive stack proof. Any extra flag bit, old non-NX flags, unsupported EFER, base or counter is rejected. All exact fault tuple, per-range permissions, pending/once-only lifecycle and VM budgets are unchanged. Host tests/build only; no claim of new injection success.
