Standalone master PIC IRQ0 subset, NEW CLOUD implementation, no runtime wiring.
Only PIT0 cumulative rising-edge sequence may feed pic0_edges. Unique nonzero domain supplied per wholly destroyed/new guest; initial watermark is actual source snapshot, never replay historical edges. Multiple new edges coalesce IRR bit0 (8259 edge latch), not a queue of manufactured interrupts. Masked edges still latch. No other IRQ sources; slave ports/other external unmask unsupported. Master masks FF/FE/FB/FA permit IRQ0 and optional empty cascade2 only.
ICW1 exact11 resets IMR to0, clears IRR/ISR/old receipt and starts ICW2. It deliberately discards pre-reset interrupt latch but preserves source watermark. During initialization source transitions advance watermark without capture. ICW2 aligned>=20; ICW3 exact04; ICW4 01/03 (8086/AEOI). Real IMR remains0 until explicit OCW1; mask_pending blocks peek/delivery in this unsupported all-lines-enabled transient. No false FF readback. Owner runtime must apply its IF/initialization policy; this pure module doesn't inspect VMCS.
OCW3 0A reads IRR,0B reads ISR; OCW2 20 nonspecific and60 specific IRQ0 EOI clear only modeled ISR0. Empty EOI is harmless. Rotation, poll, special masks, other modes/IRQs rejected unchanged. Active ISR0 blocks further IRQ0; AEOI accepted delivery doesn't set ISR.
reserve retains IRR and freezes guest PIC access, returns unique never-wrapping token/vector and snapshots source sequence. Source edges alone may arrive while reserved. On VERIFIED delivered receipt, accept clears reserved latch and preserves any post-reservation arrivals as new IRR; ISR set unless AEOI. This defines a two-phase logical acknowledge boundary at reservation, committed only by successful VM-entry receipt; it is not literal hardware INTA timing. On DEFINITE no-entry, cancel leaves IRR set, preserving merged old/new arrivals. Unknown entry must quarantine at owner, not call cancel/accept speculatively. Config writes/EOI blocked during reservation to preserve snapshot. Completed latest receipt idempotent (no second ISR/IRR action), invalidated by ICW1. Tokens/domain validated; previous canceled/older tokens rejected.
All false returns unchanged state/output. No callbacks/VMWRITE/host port calls; caller must clone model before fallible RIP commit for guest I/O. No IRQ injection implemented here. Existing LEI after-entry receipt, vectoring ownership, window/HLT and source transfer remain integration work, no Linux timer acceptance claim.
