Host-only glue of standalone pic0 and existing linux_external_irq (LEI).
Fresh pgg_init binds exact PIC pointer/domain. Before: validate PIC via no-change copy/edge-watermark check, refuse existing reservation/event; pending PF/highPF returns READY without staging (outer owns that event). No eligible IRQ returns READY. IF/STI/MOVSS deferral returns DEFER_WINDOW with no writes/reservation: OUTER MUST schedule/set reviewed window handling, not treat as injected. LEI now permits halted activity1 only without interruptibility blocking; activity2+ remains rejected. The opt-in legacy coordinator separately owns window/HLT helpers. This host gate result is not a VM delivery result.
Eligible vector: reserve -> stage error/length/info-last. Any failure retains token+event and stickyfailed/noresume. After verified native outcome: noentry (including recognized VM-entry failed exit) clear metadata then cancel PIC, preserving IRR. True instruction receipt clear delivered metadata then account token. New PIT edges during reservation retained by PIC; ISR0 set unless AEOI. Unknown/timer/window/exception/vectoring results fail/quarantine retaining ownership, never automatic replay. LEI receipt whitelist unchanged.
All false means caller must not authorize further guest execution, even if VMCS partially changed; safe-host state must already be proven before after callback. after true for NO_ENTRY is cleanup success, NOT guest execution/resume success. External session owns original failed start outcome.
busy covers callbacks; model config/EOI blocked while reservation, only monotonic source-edge ingestion allowed. Unknown completion or failed accounting needs owner fatal/quarantine/destroy handling. Do not reset glue/PIC until entire guest domain safely destroyed. No standalone recovery retry API included. Source context lifetime, same BSP and before/after exactly-once maintained by owner. This module does not itself set host readiness or validate all VMCS fields.
No dispatcher/service/clock edits, no APIC enable, no VM. test.sh uses real pic0.c and linux_external_irq.c with ASanUBSan/freestanding. Covers all three stage/clear/cancel writes, reentrancy, PF exclusivity, deferral, HLT rejection, noentry, edge duringreservation+EOI, entryfailed, unknown and vectoring quarantine.
