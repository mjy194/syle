# Lossless bounded deferred observer encoding

New isolated module only, no old fot/runtime/default changes. Caller provides<=2MiB stable nonalias buffer.512-entry writer dictionary and independent decoder dictionary live inside state, not dynamic stack. Text<=512 first occurrence DEF(tag1,idLE16,lenLE16,copiedbytes); reference REF(tag2,idLE16); dictionary full or longer text RAW(tag3,lenLE32,copiedbytes). Each DEF also represents its first emitted text event. HEX(tag4,LE64) reconstructs exactly19 bytes `0x`+16 lowercase digits+newline. No input pointer retained, empty and embedded-NUL text supported. All control fields explicitly byte-read/written.

Whole record capacity preflight precedes dictionary/publication changes. Full dictionary raw fallback is normal and lossless. Overflow drops whole event, sets stickyfailed/incomplete, emits one out-of-band marker; retained complete encoded prefix can still be flushed once. Subsequent events count as dropped, and caller must forbid guest entry. First flush switches immediate and irrevocably marks flushed. First independent decode validates entire prefix and separately checked logical length/event totals against accepted deferred events (not requested including drops); no sink before validation succeeds. Second decode reconstructs in order. Buffer and state are immutable except documented module actions throughout both passes, including callbacks. Callback reentry fails closed; arbitrary malicious pointer writes cannot be prevented by this C interface. Structural validation is not cryptographic corruption detection of payload bytes.

Sink false may emit a partial invocation. That event is attempted only once, all later sink work forbidden; no retry, no duplicate flush. decoded counters represent successfully returned callbacks, attempted bytes include marker and uncertain callback, dropped bytes represent rejected input not uncertain transport. Native UART wrapper cannot claim hardware delivery acknowledgement. Counters saturate+fail on arithmetic overflow.

Tests: exact direct/deferred bytes and call order; dictionary copies after source mutation; embeddedNUL/empty via random oracle;513byte/raw and514unique strings; overflow boundary; malformed tags/IDs/lengths, every prefix truncation before any sink; sink failure at each decoded event, callback recursion and repeatedflush; input/state/buffer overlap rejection; randomized10k event oracle; full2MiB buffer with233016 hex events independently hashed against reference formatting. No clocks/heap/native/KVM. Compression measures storage only: CPU encoding overhead remains real and influences later real samples; no runtime speed or deadline benefit claimed.
